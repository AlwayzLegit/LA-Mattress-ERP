Design notes — closing the nine phases

Jobs asked one question of every sheet: can the salesperson finish the sale with a customer watching, without a manual. Two things failed the first pass and were fixed here: the picker's From select was not in the tab order before the search field (it is now 2nd, because it changes what the search shows), and the cancel confirm's default focus was on the destructive button (it is now on Keep order).

Ive closed by removing the last decorative element in the system — the shimmer on skeletons was reduced from a moving gradient to a static two-tone bar under reduced motion, and the team agreed the static version is fine everywhere; the moving one stays only because it tells a waiting person the machine is alive.

What we removed, across all phases
  • 26 top-level sidebar links → 5 collapsible groups, role-trimmed.
  • Six equal KPI tiles → one headline with two baselines.
  • Five grey status pills → six chips with glyph + word + colour.
  • A plain-div product picker → a real dialog with From as the loudest control.
  • "Loading…" as a screen → skeleton with a 4s budget, then an error that names the draft.
  • Per-week paging on a five-week board → Week / Month modes with capacity on every day.
  • Clickable rows without anchors → links, aria-sort, real dialogs, visible focus everywhere.
  • ⌘K on Windows → platform-aware chip.
