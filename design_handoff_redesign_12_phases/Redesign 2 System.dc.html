Type decision

Ive wanted one family doing everything (candidate 2, Manrope, is closest to that). Chaudhri argued the register needs a number that reads from two metres, which is a condensed-leaning display cut, not a text face at a bigger size. Archivo's tabular figures hold a column at 13px and a total at 44px without re-kerning. Forstall ruled out Space Grotesk (candidate 3) because its lowercase g and a slow down reading a customer's name at speed. Winner: candidate 1. Public Sans is a government-issue workhorse — dull on purpose. JetBrains Mono's slashed zero settles 0/O in SKUs.

Later: a licensed grotesk (Söhne or similar) would replace Public Sans if the owner buys one; the scale below does not change.

Design notes

Ive argued for radius 0 everywhere — "a tool, not a toy". Matas countered that a 5px button radius is what tells a finger it is a button in a sea of table cells, and that a 3px input radius separates a field from a cell in the same row. Jobs kept both radii and struck the 9px card radius the current design uses: cards inside cards was on the avoid list, and a sheet with a hairline does the same job.

Chaudhri wanted status chips to be filled solid so they read at register distance. Ive: six solid chips in a table is a bag of sweets. Settled on tinted fill with a 1px border of the same hue and a 600-weight word; the glyph carries the state for anyone who cannot see the hue. Contrast checked: every fg/bg pair clears 4.5:1 (ratios in the token table).

Forstall insisted the error state name where the draft is and what happens next. The audit's "Loading…" was a state nobody wrote. Every skeleton has a 4-second timeout that becomes the error component with Retry.

What we removed
  • The 9px card radius and the card-in-card pattern.
  • Grey "pill" status with dot — replaced by chip with glyph + word.
  • A filled destructive button. Destructive is outlined only.
  • Icon-only buttons except Close (×) which carries an aria-label.
  • Purple, gradients, and a second accent. One navy.
  • Font-size 11px anywhere text is read (11px remains only for uppercase column labels at .05em tracking).
